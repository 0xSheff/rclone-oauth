Privacy policy

rclone wx-9 ubuntu · last updated 2026-09-23

What this app is

A personal, non-commercial OAuth client used only by its owner (github.com/0xSheff) with the open-source rclone tool, running locally on the owner's computer.

Data accessed

With the owner's consent, the app accesses the owner's own Google Drive through Google's APIs in order to read and write the owner's files — for backups and file access from the owner's computer.

Data collection and sharing

No data is collected, stored, sold, or shared by the developer. Files move only between the owner's computer and Google's servers. OAuth tokens are stored locally in rclone's configuration on the owner's computer and are never transmitted anywhere else.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
